NEON VOID · 星海弹幕
====================

【怎么玩】
1. 把 index.html 拖进浏览器（Chrome / Edge / Firefox 都可以），立刻开玩。
2. 手机上用浏览器打开本文件，手指拖动操控，右下角是炸弹按钮。

【操作】
  移动          方向键 / WASD / 手指拖动
  精准移动      Shift（显示判定点，速度减半）
  炸弹          X（清屏 + 1.8 秒无敌）
  暂停 / 静音   P 或 Esc / M
  开始 / 重来   Enter 或点击屏幕

【说明】
  完全离线：单个 HTML 文件，没有外部图片和音频，画面与音效全部由代码生成。
  最高分保存在浏览器本地。
